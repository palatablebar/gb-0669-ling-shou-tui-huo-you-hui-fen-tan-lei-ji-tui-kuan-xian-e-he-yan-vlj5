# 使用场景

零售财务数据专员收到各业务系统导出的月度台账，在采信页选取样例或粘贴CSV，逐模块检查计算结果和隔离原因，最后复核归档。

业务核心：订单级优惠以最大余额法分至商品最小单位，部分退货按原分摊反向回收，累计退款不超过实付，运费只在规则满足时退一次。

并发场景：门店与线上同时看到同一订单的最后一件可退商品，财务当天必须给出唯一退款结果。资格只认实际退货时间（UTC+事件号），不认同步到达先后；落败渠道在核算页与渠道页看到 ELIGIBILITY_LOST 拒因及资格取得方。同事件号重试幂等不重复冲减；规则更新后旧结果失效，恢复重算不丢失已确认退货。

样例问题：全角金额、重复退货、超量退货、尾差、混币、渠道尾件争夺。干净与脏样例走同一条处理链，contest 样例专用于并发资格演示。

限制：不覆盖换货补差价、积分抵现、多币种汇率与外部支付退款；文件内须包含完整原销售单及售后事件，跨文件结果不自动串接。
